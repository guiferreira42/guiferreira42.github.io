# Cores Principais do Portfólio

Este documento lista a paleta de cores padrão utilizada na estrutura deste portfólio. As cores estão configuradas de forma customizada no arquivo de configuração do TailwindCSS, inserido nos `<head>` de `index.html` e `projetos.html`.

## Tema Base (Estilo GitHub Dark)
- **Fundo Principal (`github-bg`)**: `#0d1117` - Usado no background da página e sessões alternadas.
- **Fundo de Cards (`github-card`)**: `#161b22` - Usado no fundo dos projetos, timeline de experiência e cards.
- **Bordas (`github-border`)**: `#30363d` - Usado para divisões sutis em linhas e delimitadores de blocos.
- **Texto Primário (`github-text`)**: `#c9d1d9` - Branco suave para títulos e textos de maior foco.
- **Texto Secundário (`github-muted`)**: `#8b949e` - Cinza para descrições longas, detalhes e rodapé.

## Cores de Destaque (Accent Colors)
Utilizadas estrategicamente em ícones, botões (fundo e hover), sombras de brilho profundo e tags para orientar o olhar do recrutador ou visitante.

- **Azul Primário (`accent-blue`)**: `#3464ff`
  - Utilizado no Herobanner, no botão principal do perfil e como cor de destaque do **Projeto AWS Data Lake**.
- **Azul Claro (`accent-lightblue`)**: `#79c0ff`
  - Utilizado em tags técnicas, áreas de BI e no **Projeto de Cibersegurança**.
- **Laranja Databricks (`accent-databricks`)**: `#FF5F43`
  - Um coral suave/laranja vibrante criado para destacar o ecossistema do **LogiFlow Analytics** e seções de Pós-Graduação, garantindo harmonia visual e um tom moderno sem a agressividade do vermelho puro.
- **Verde Função (`accent-func`)**: `#27ae60`
  - Para lógicas de aprovação, badges ou alertas positivos.
- **Rosa Keyword (`accent-keyword`)**: `#ff7cc4`
  - Tonalidade tech para brilhos ou sintaxe de código (se aplicável).
