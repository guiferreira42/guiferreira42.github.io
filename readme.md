## 📋 Sobre

Portfólio desenvolvido para apresentar minha trajetória profissional, habilidades técnicas, formação acadêmica e projetos de dados reais. O site é **estático**, hospedado no GitHub Pages, com design inspirado no tema dark do GitHub.

## 🏗️ Estrutura do Projeto

```
guilherme-ferreira42.github.io/
│
├── index.html              # Página principal (Home)
├── projetos.html           # Página de cases e projetos detalhados
│
├── css/
│   └── style.css           # Estilos globais e utilitários custom
│
├── js/
│   └── script.js           # Scroll reveal, ano dinâmico no footer
│
├── assets/
│   ├── picture_perfil.jpg  # Foto de perfil
│   ├── badge_databricks.png
│   ├── logo_databricks.png
│   ├── projeto_1/          # Assets do Case 1 — Cibersegurança
│   └── projeto_2/          # Assets do Case 2 — AWS Data Lake
│
└── .gitignore
```

## 📂 Páginas

### `index.html` — Home
- Hero com foto, título e frase de impacto
- Bloco de Skills com indicadores de proficiência
- Certificação Databricks
- Linha do tempo de Experiência Profissional
- Cards de Formação Acadêmica
- Prévia de Projetos & Cases

### `projetos.html` — Cases
- Navbar fixa com menu de navegação por projeto
- Case 1: **Análise de Incidentes de Cibersegurança** (Power BI)
- Case 2: **Data Lake & Analytics na AWS** (S3 · Glue · Spark · Athena · Power BI)

## 🚀 Como rodar localmente

Não há dependências. Basta abrir o `index.html` em qualquer navegador moderno, ou usar uma extensão como o **Live Server** no VS Code.
